# Temperature Converter (Python)

A simple command-line temperature converter built with Python. This beginner-friendly project converts temperatures between **Celsius (°C)** and **Fahrenheit (°F)** based on the user's input.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Accepts user input from the terminal
* Handles invalid unit selections
* Uses basic Python concepts such as:

  * Variables
  * User input
  * Conditional statements (`if`, `else`)
  * Arithmetic operations
  * String formatting
  * `round()` function

## How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/ArshfaAybani/Command-line-tempConverter.git
```

3. Navigate to the project folder:

```bash
cd Command-line-tempConverter.py
```

4. Run the program:

```bash
python tempConverter.py
```

## Example

```
Is Temperature in Celsius or Fahrenheit (C/F): C
Enter the Temperature: 25
Temperature in Fahrenheit is 77.0 F
```
