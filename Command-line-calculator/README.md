# Python Calculator

A simple command-line calculator developed in Python to practice fundamental programming concepts. This project was created during the early stages of learning Python and focuses on implementing basic arithmetic operations through a clean and beginner-friendly codebase.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input handling
- Basic conditional logic

## Technologies Used

- Python 3

## Purpose

The objective of this project is to strengthen understanding of core Python concepts, including:

- Variables
- Data types
- User input (`input()`)
- Conditional statements (`if`, `elif`, `else`)
- Arithmetic operators
- Basic program flow

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ArshfaAybani/Python-Learning.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Command-line-calculator.py
   ```

3. Run the program:
   ```bash
   python Calc.py
   ```
