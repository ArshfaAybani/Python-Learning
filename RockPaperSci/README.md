# Rock, Paper, Scissors (Python CLI)

A lightweight, command-line **Rock, Paper, Scissors** game written in Python. Play against a random computer opponent and keep playing rounds until you decide to quit.

## Features

- Interactive terminal prompts for choosing **Rock (`r`)**, **Paper (`p`)**, or **Scissors (`s`)**
- Randomized computer opponent using Python's built-in `random` module
- Win/loss/tie detection with replay loop (`y` to continue, `n` to exit)
- Zero external dependencies—runs on any standard Python 3 installation

## Prerequisites

- **Python 3.x** installed on your system

## How to Run

1. Save the code to a file (for example, `rock_paper_scissors.py`).
2. Open a terminal or command prompt and navigate to the file's directory.
3. Run the script:

   ```bash
   python rock_paper_scissors.py
