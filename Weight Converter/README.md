# Python Weight Converter

A simple command-line weight converter built in Python. This project converts weight between **kilograms (K)** and **pounds (L)** based on the user's input.

## Features

- Convert kilograms to pounds
- Convert pounds to kilograms
- Rounded output for better readability
- Handles invalid unit input

## Technologies Used

- Python 3

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/ArshfaAybani/Python-Learning.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Weight Converter
   ```

3. Run the program:
   ```bash
   python weightConverter.py
   ```

## Example

```
Enter your weight: 60
kilogram or pounds? (K or L): K

Your Weight is 132.3 Lbs.
```
